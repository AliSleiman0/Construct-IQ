Built as a greenfield module cloned from inspections end-to-end (schema + member-scoped service + permissions in both seed paths + FE types/api/hooks/list/detail + sidebar). **Eng-raises / manager-answers:** SITE_ENG holds `create/read/update:rfis`; answering is `POST /rfis/:id/answer` gated to `manage:rfis` (PM) — the asker can't self-answer; no new verb/superset change needed.
